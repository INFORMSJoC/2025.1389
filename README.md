## Code Repository

The repository contains YAML file (named `ocrt.yml`) to create the environment necessary to train the OCRT model. To create the environment you can use the following command:

```bash
$ conda env create --file=ocrt.yml
```

This will create a virtual environment with the name `ocrt`. You should be able to see this environment if you run the following command:

```bash
$ conda env list
```

If `ocrt` is listed in the virtual environments, that means that the environment is installed successfully. You can activate the environment using the command below:

```bash
$ conda activate ocrt
```

Currently, the repository is available for training the OCRT model.

## Data

To be able to start with the runs, we need data. There are 3 datasets used in the repository. All of these are available within the `data` folder. In particular, there are synthetic datasets (generated by running the `generate_constrained_dataset_with_nonlinearity()` function within the `library/Constrained_Data_Generation.py`), which has the following naming format according to the number of targets and dataset size: `df_size_<DATASET_SIZE>_targets_<NUMBER_OF_TARGETS>_seed_<SEED>`. There are also hierarchical time series datasets with and without noise.

## Parameters of OCRT

- `ocrt_min_samples_split`: Minimum number of instances that a decision node should have in order to perform splitting.
- `ocrt_min_samples_leaf`: Minimum number of instances that a node should have in order to become leaf node.
- `ocrt_depth`: Maximum depth of OCRT.
- `evaluation_method`: Evaluation metric that is used to calculate the gains of the split candidates. Available values are `mse` (i.e. Mean Squared Error), `mad` (i.e. Mean Absolute Deviation), and `poisson` (i.e. Poisson Deviation).
- `prediction_method`: Prediction approach used in splitting. Available values are `mean` (i.e. to return the mean of target values as prediction), `medoid` (i.e. to return the median of target values as prediction), `optimal` (i.e. to return the optimal values the optimization problem that minimizes MSE objective function).
- `prediction_method_leaf`: Prediction approach used in leaves. Available values are `medoid` (i.e. to return the median of target values as prediction), `optimal` (i.e. to return the optimal values the optimization problem that minimizes MSE objective function).

## Parameters of RF

- `ocrt_params`: All OCRT parameters.
- `n_estimators`: The number of regressors used to construct random forest.
- `max_features`: Maximum number of features to be used while training each regressor.

## Experiments

After the environment is activated, you can replicate the runs with results presented in the paper. The dataset parameter accepts the following values: `synthetic_manifold`, `hts`, `hts_noisy`, and `synthetic_illustrative`. To reproduce the performance tests on the synthetic datasets (Section 5.1 and Appendix C) and the hierarchical time series (Section 5.2), execute the `experimentation_c` script using the corresponding dataset argument (`synthetic_manifold` for the former; `hts` or `hts_noisy` for the latter). The experiments on generalized loss functions (Section 6.1) and the end-to-end learning framework (Section 6.2) can be reproduced using the `experimentation_illustrative_c` and `experimentation_e2e_c` scripts, respectively. For the former, set the dataset to `synthetic_illustrative`, whereas for the latter, use `synthetic_manifold` with default parameter values provided in the scripts. To be able to retrieve multiple results at once, some of the parameters mentioned above are collected together to iterate over with the variable that has the suffix `_list`.
